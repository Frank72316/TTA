# 两次光度扰动放在原值两侧，会发生什么？

同样使用原图、5% 和 10% 两次扰动，只改正负方向的配对方式。换成反向搭配后，候选分差对配方的方差在亮度和对比度下分别下降 **88.45% 和 88.01%**；期望严格选对数却分别从 **175 降到 174**、从 **176.5 降到 174**。两种搭配的期望有向分差在每对图上都相同。

| 因素及搭配 | 配方方差的跨对均值 | 选对 / 选错 / 同分（期望对数） | 相对原图错→对 / 对→错 |
|---|---:|---:|---:|
| 亮度，同向 | 1.37311×10⁻⁶ | 175 / 81 / 0 | 2.5 / 2.5 |
| 亮度，反向 | 1.58529×10⁻⁷ | 174 / 81.5 / 0.5 | 2 / 2.5 |
| 对比度，同向 | 1.18300×10⁻⁶ | 176.5 / 79.5 / 0 | 3.5 / 2 |
| 对比度，反向 | 1.41895×10⁻⁷ | 174 / 81.5 / 0.5 | 2 / 2.5 |

主比较为亮度反向减同向，严格选对率差 **−0.391 个百分点**，按 256 个图对配对重采样的 95% 区间为 [−0.977, 0.000]。对比度为 −0.977 个百分点 [−1.953, 0.000]。固定 5% 版本的符号比较两种策略，亮度平均纠正 2.5 对、改错 3.5 对，另有 0.5 对由错变同分。对比度纠正 2 对、改错 4 对，另有 0.5 对由对变同分。原图为 175 对严格选对、81 对选错。[所有九格转移](transitions.csv)

**为什么波动会缩小？** 令 m 为人工赢家减另一候选的分差，dₐ 为正、负 a 两档分差之差的一半。同向两配方的总体方差为 (d₅+d₁₀)²/9，反向为 (d₅−d₁₀)²/9。逐对核对两式。d₅d₁₀ 为正、负、零的图对在亮度下为 **215 / 30 / 11**，在对比度下为 **209 / 39 / 8**。同号时反向配对会减少波动，而原先方向判错的图对也会失去一些跨过零的机会。

**同一图对就能看到两个方向。** N015 在固定 +5% 亮度时，把 +10% 换成 −10%，聚合分差从 −0.000936 变成 +0.000529，纠正了选择。固定 −5% 时把 −10% 换成 +10%，分差从 +0.000692 变成 −0.000773，选错了同一对图。这里的波动限于冻结图上更换数字增强配方；真实曝光变化需要另外采集或测试。[逐对分差](pair_results.csv)
