# 第三次评分值得用在亮度上吗？

**追加亮度**。从“原图＋一次对比度”出发，每 400 对期望严格纠正 **1.125 对**、严格改错 **0.9375 对**，另有 0.25 对从同分转为选对。期望严格选对数净增 **0.4375 对**。

**改用第二次对比度**。相对同一起点，期望纠正 **0.833 对**、改错 **0.667 对**。它减少了改错，也漏掉亮度能救回的 T064、T361。固定三次预算时，两种方案的选对率仅差 **0.026 个百分点**，现有证据不足以认定对比度可以替代亮度。

**直接停在两次**。删掉第三次亮度的损失为 **+0.109 个百分点**，配对双侧 95% 区间 **[−0.188, +0.438]**，单侧 95% 损失上界 **0.375**，低于预设容差 **0.5**。在这项测试中支持两次停止。Asus RTX 4090 上每图对少用两次视觉编码，配对延迟中位数节省 **45.96 ms（27.8%）**。

**第三次评分帮了谁？** 124 个原图错例中，若只要求最终至少一套选对，亮度追加独有 T064（1/16）、T361（6/16），两策略共有 T012、T190，对比度追加独有 0 对。若进一步要求同一个首次对比度已严格选错，只有追加亮度能救回 T064（1/16）、T190（1/16）、T361（6/16）；第二个对比度在这 124 对中没有一次严格错→对。它在全体中的 0.833 对纠正均来自原图本来正确、首次对比度使其选错的样本。[逐例搭配数](original_errors.csv)

**为什么两次可以停，三次却不能直接换？** 停止检验考查平均准确率的损失上界。替代还要求保留特有纠正。纯对比度漏掉了纯亮度能救的 2/124 对，漏纠正比例为 1.613%，单项单侧 95% 上界 4.990%，已超过 3% 容差。T064 在停止时选 B，亮度 0.90 刚好让人工赢家 A 反超；T017 在停止时选对 B，亮度 1.10 让它改选 A。[真实案例图](cases.png) · [五项替代判据与全部转移](details.md)
