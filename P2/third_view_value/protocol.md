# 第三次评分的价值 · 测试前冻结协议

唯一主问题是在已经评过原图和一个对比度视图后，删去额外亮度视图，期望严格选对率最多损失多少。容差为 0.5 个百分点，单侧 95% 上界严格低于容差才支持停止。独立性指相对本项目既往使用的提示词及图片。测试样本不参与方案选择。

## 样本、评分与预算

- ImageRewardDB 官方 test，修订 c493721e19e296eb615420036f2a2eed08412bb4。按 64、256、88 三份历史清单排除提示词 ID、NFKC/casefold 后合并空白的文本、图像 UUID。排序后用 Python Random(20261128) 无放回抽 400 个规范化文本，合格不足时全取；同文本的合格 prompt_id 中均匀抽一组，在不同正名次的所有无序候选对中均匀抽一对、随机分配 A/B。小名次胜，P0 保留原字符串。前两对作冒烟。历史 256 对仅用于检查实现和精度规划。
- O 为 RGB 原图。B 和 C 分别从 O 独立用 Pillow Brightness 和 Contrast 生成，系数 0.90、0.95、1.05、1.10。使用项目固定的 HPS v2.1、验证预处理、单图单提示 FP16 评分路径（归一化图文特征点积）；同题文本编码一次。保留输出原生可精确表示的浮点值和模型输入哈希。两候选用同一配方。按人标赢家减输家统一有向分差。配方分差求和后按正、零、负分别判严格对、同分、严格错，float64 聚合。
- O 一套，停止 O+C1 四套，追加亮度 O+C1+B1 十六套，追加对比 O+C1+C2 十二套有序取样（C2≠C1），纯亮度 O+B1+B2 六套无序取样。各套先决策后平均。涉及两个追加动作的转移固定 C1，B1、C2 条件独立，精确枚举 48 套；参数套数只作概率分母。
- 同硬件、图像 batch=1、每请求一次文本编码。在冻结清单前 64 对上测内存中的压缩图片字节至输出判定的同步墙钟时间，包含解码、变换、预处理、传输和编码，排除权重加载、磁盘读取与缓存写入。三种 K 在每对内轮换执行顺序；用固定随机种子均匀选该对共用的 C1 和额外 B1，先用前两对预热。记录各 K 的中位数、P95，以及配对 K3−K2；基准重复计算单列。

## 统计与机制

- L 为混合三次减停止两次的期望严格选对率，按完整提示词配对 bootstrap 10,000 次，种子 20261128。报双侧 95% 百分位区间和单侧 95% 上界；若逐提示词差全零，用潜在非零事件的精确二项界，单侧上界 1−α^(1/n)，双侧对称使用 α/2。同分保留在全体分母。
- 有向替代按已有协议 C←B。严格选对率损失分别为 BB−CC、BC−CC；新增改错分别为原图选对样本上 CC 严格改错概率减 BB、BC 的改错概率，再除全体数。四个上界各须 <0.5 个百分点。纯 BB 可纠正而纯 CC 无法纠正占所有原始严格错例的单侧 Clopper–Pearson 上界须 <3%。同时报告单项 95% 上界和既定十个方向各五项 Bonferroni 上界（α=0.001）。替代判断使用同时界。停止只有一个主问题。
- 列出原始错例中能由 BC/CC 选对的覆盖，以及更严格的“同一 C1 下停止严格错、追加后严格对”覆盖和成功比例。列出两种追加各自九格转移及 48 套共用 C1 时的互转。直接核验第三视图有向分差与停止分差之和异号且其幅度超过停止领先时发生严格翻转。冻结顺序首先取一个仅亮度追加能从严格错中救回的原始错例，再取一个亮度使原始和停止均正确的样本严格改错；各取首个符合的 C1、B1 档位。若无则列零。图展示两候选的 O/C1/B1。开发分析、辅助替代判断与正式主指标分列。
