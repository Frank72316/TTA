# 冻结设计

输入为原 COCO 实验全部 64 对、128 张原始照片及种子 42 的双替换词表。所有候选共享原有 X/Y 角色，三条线和两类名词全部测量。HPS v2.1、官方验证预处理、eval、单图单文本及 FP16 相似度沿用原实验。

| 要素 | 冻结规则 |
|---|---|
| 分线 | 在原 RGB 有效画面以 W/4、W/2、3W/4 的连续坐标切分。渲染时将线坐标按最近整数取整，半数向上；左为 [0,k)，右为 [k,W)。遮挡值 RGB(128,128,128)。原画布尺寸保持一致。 |
| 分组 | COCO xywh 裁到原图边界，分别算连续线两侧的可见框面积比例。以精确分数与 3/4 比较，恰等计入。双方达标且在相反侧为分开，同侧为同侧，其余为部分跨线。单独记录整数线重新分类的差异。 |
| 主指标 | 25% 与 75% 中恰有一次分开、一次同侧的照片。每张计算有向证据的“分开减同侧”，再取真词增量减种子 42 双替换增量的跨照片均值。两种词用同一符号。 |
| 区间与方向 | 分开方向以分开那条线命名。10,000 次百分位 bootstrap，种子 42，按合格照片所属的原始图对整簇重采样，以抽中的照片总数作分母。分方向时在相应簇内重做相同计算。严格正、负、零分别是正确、颠倒和同分。 |
| 中线诊断 | 所有 64 对，比较真实左图 E 减真实右图 E；分别测真词与替代词，再比较两者相差的正确率。旧半图重新用原生分数计算。这项配对任务和主分析的单照片证据分开报告。 |
| 选例 | 在可再发布改图的 CC BY 照片中，按原图对和 A/B 顺序，分别取首个 Δ真>0、Δ真<0 的主分析照片。冒烟取两张已标注 CC BY、两目标均可在至少一个视图完整保留的照片。 |

每条线的每张照片使用两个视觉输入，每组名词使用四个相似度；视觉特征在真词与替代词间共享。框只参与分组、方向评价与展示。
