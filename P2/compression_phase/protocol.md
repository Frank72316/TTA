# 冻结方案

每图 O＋一个版本。JPEG 质量 85、4:4:4、非渐进、禁用 optimize；左右上下均用 reflect，左/上 16＋相位偏移，右/下补至至少 16 并使填后边长为 8 的整数倍。四相位 (0,0)/(4,0)/(0,4)/(4,4)。主比较为均匀 JPEG 相位减 O 严格选对率。旧 64 对只读图像，在实际可见区以 RGB 转 Rec.601 亮度一阶差分能量相对原图的变化校准 GaussianBlur。候选半径 0.1 至 2.0，步长 0.1，最小化每图相对于 JPEG 四相位平均能量变化的绝对差的均值；同分取较小半径。误差容限为该平均绝对差不超过 JPEG 平均绝对能量变化的 25%。冻结后再运行 256 对。四套高斯裁回须逐像素相同，先检查坐标之后可复用重复张量。

原始图对等概率整对有放回重采样 10,000 次，种子 42，使用百分位 95% 区间。同分单列。前两个冻结 ID 做冒烟检查。按冻结 ID（再按预设参数顺序）取首个有益和首个有害的实际案例；深度以空间收益的正负选例。结果限于当前样本。
