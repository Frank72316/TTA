# 冻结方案

使用 256 个冻结 P0 图对。位移为四方向各 3%，整数半数向上，分别 reflect 和 edge；两者均与 O 等权，每方向先判定。主比较为 edge 减 reflect 严格选对率。记录全部有向分差、原图与模型输入像素差、实际改变掩膜。凡两策略判定不同且任一聚合分差绝对值在相关原生分数最大 FP16 间距一步以内，重算该配方两侧 O/ref/edge，保持原评分精度，单列结果。

原始图对等概率整对有放回重采样 10,000 次，种子 42，使用百分位 95% 区间。同分单列。前两个冻结 ID 做冒烟检查。按冻结 ID（再按预设参数顺序）取首个有益和首个有害的实际案例；深度以空间收益的正负选例。结果限于当前样本。
