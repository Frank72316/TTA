# 实验目标

问题指向鸟冠或翅膀时，在相同预算下，把第二个视图分给相应部位是否提高颜色属性判断？这是带定位标注的机制实验。框或关键点只是额外空间信息，颜色真值只能进入评价。

# 给 Asus 上 Codex 的完整提示词

请在 Frank72316/TTA 的 P2/part_conditioned_tta/ 执行本实验，复用 P2/within_image_partition 的 HPS v2.1、tokenizer、官方验证预处理与相似度实现。在一张空闲卡用 UUID 绑定，先跑 C001–C002，再断点续跑。使用本包已冻结的 pairs.csv，按 image_id、图片相对路径、A/B 对齐官方 CUB_200_2011/images/；仅缺图片时获取原始数据，勿使用已经裁剪、缩小或附带标注画框的版本。记录数据归档、照片、模型与最终输入的哈希。若官方标注与清单不一致，记录并定位差异。

1. 任务含 96 对互不重复的照片。每对中鸟种一致，使用相同颜色词，鸟冠题与翅膀题赢家相反。固定两句英文为 “The bird has {color} plumage on its crown.” 和 “The bird has {color} plumage on its wing.” 两道题分别在两张候选间按模型分数严格选图，不强制分配一左一右；保留精确同分。推理入口传入图片、颜色词、部位点和问题，勿把颜色真假、确定度或鸟种输入评分流程。

2. 每张照片做四个视图：O 原图、H 鸟冠点裁剪、W 可见翅点裁剪、C 画面中心裁剪。所有局部视图用同一源图尺度和处理方式：方窗边长 max(1,floor(0.30*min(画宽,画高)+0.5))，以原始标注像素坐标为中心（全程记录原始坐标及取整），中心窗用几何画心。同一四舍五入规则处理左上角，越界中性灰 RGB(128,128,128) 补足，再走同一 HPS 预处理。双翼都可见时使用清单冻结的左翼，不能按颜色、得分或画质重新挑选。记录填边比率、两个部位窗口 IoU、另一部位点是否落进窗口；保留窗口重叠的图对。冒烟图另存原图标点和三个实际裁块，核对坐标和左右翼标记。

3. 对每个视图都问同样的两道题。原图和两个名词模板的文本/图像特征可复用；每张图正常只需四次视觉编码。保存 scores.csv：image_id,view,query,score，view 取 original/crown/wing/center，query 取 crown/wing。每张图八条分数，总共 768 个视觉输入、1,536 条唯一相似度；另外记冒烟缓存与实际耗时。保留原始分数精度后再做平均。

4. 策略每题分别使用：只看 O；O＋中心窗；O＋题目对应部位；O＋另一部位。双视图策略一律等权先平均再判赢家，每张候选每道题使用两个视觉输入及两个图文分数。聚合过程和权重在两道题上一致。主比较是两题等权的“对应部位减另一部位”严格选对率差，单题同分按未严格选对计。按物种整簇 bootstrap 10,000 次、种子 20261128，保留每对双题，所有图对在点估计中等权。列出鸟冠题与翅膀题的两项差，若只有一个方向有优势，要如实说明。两项次比较为“对应部位减原图”和“对应部位减 O＋中心窗”。运行本包 analyze.py 并独立复核结果。

5. 补充双题均对的完整对数、单题纠正/改错/同分及每个方法的相对原图转移；单列 29 对四个属性标注均为 definitely 的样本作描述性敏感性分析。对主分析中有重叠或补边的裁块列数量，记录可见背景或遮挡的实例。全表保留原始 96 对。三种裁剪共用原图、不新增问法、无须人工盲评；若 HPS 在两个部位均不能可靠辨色，照实给出结果。

6. 输出一页中文 report.md、逐题和逐对结果、四格“问题部位×所看部位”表、两例真实图、复现命令。若确有案例，分别展示“同一对鸟，看对部位后两题都对”和“看对部位仍失误”。报告首页写清：问哪个部位是否改变看哪里更好？对应部位有没有超过原图及同预算中心裁剪？使用标注点的收益与部署所需定位成本分开表述。

# 来源与复算

- Caltech 官方数据页：https://www.vision.caltech.edu/datasets/cub_200_2011/
- 标注镜像使用 Hugging Face Jaszczurix7652/CUB-200-2011，版本 ecc431bb99dd6ec05d0c1098dd94d669da916a7a。读取逐图 attributes、可见 part_locs、split、species 和路径；不使用类级属性，不把“其他颜色为真”充当阴性。名词为 has_crown_color 与 has_wing_color，图级 is_present 明确为 0 或 1，certainty_id 至少为 3。
- 执行 freeze_pairs.py 时将原始 attributes.txt、train_test_split.txt、image_class_labels.txt、images.txt、part_locs.txt、image_attribute_labels.txt 放入同一目录。示例：python freeze_pairs.py --meta metadata --out pairs.csv 。核验 SHA256SUMS。
- analyze.py 需要 Python 与 NumPy。评分后使用 python analyze.py scores.csv --out results 。包内没有模型推理结果，没有分发照片。
