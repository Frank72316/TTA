# NYU 米制深度：三次推理的平移方向搭配

本协议先于新视图推理冻结。样本沿用 depth_adaptive_budget 的 128 帧、95 个 NYU 场景及原顺序，属于已用开发样本。模型沿用 Depth Anything V2 Metric Indoor Small，revision `8078d68a9c75a972131914f6afd0c1723be0da7f`，同一预处理，单图 FP32 eval，禁用 TF32。

1. 每帧取 O 和 L2、R2、L4、R4。源图水平位移为 `floor(w*pct/100+0.5)`，左负右正，独立从 O 反射补边。模型预测经双三次插值回原尺寸（align_corners=False），按 x+dx 逆对齐。所有策略共用原图坐标下五视图真实可见交集，再与毫米真值转换为米后满足 (0,10] 的像素取交集。评价、平均、乘积和平方均使用 float64。
2. 冻结配方 LL=O/L2/L4，RR=O/R2/R4，LR=O/L2/R4，RL=O/R2/L4。各配方先在每个像素平均三个对齐预测，再算该帧有效区 MSE。同向为 LL、RR 两个 MSE 的均值；反向为 LR、RL 两个 MSE 的均值。各类部署每帧等概率选一套配方，预算三次；离线每帧比较五种唯一视图。
3. 唯一主指标 G 为同向 MSE 减反向 MSE，每帧等权，正值表示反向更好。次比较均以原图 MSE 减策略 MSE，正值表示较原图省下误差。三个差的百分位区间均用同一组 10,000 次配对簇 bootstrap，种子 20261128。按场景名排序，有放回抽 95 簇，每次保留被抽中场景的全部帧与所有策略，分母取副本的实际帧数。改善/变差/持平按逐帧差的实际符号统计。
4. 独立用 D2=L2−R2、D4=L4−R4 计算像素贡献 D2×D4/9，分别将正值和负值在该帧全部有效像素上求和并除以同一分母，然后按帧等权汇总。验证乘积均值等于实测 G，且正、负贡献之和等于 G。验证两种策略在随机选配方时的平均预测逐像素相同。机制公式只作核验。
5. 前两帧 nyu_1180、nyu_0325 冒烟。合成坐标图与真实 RGB 检验左右符号、半数向上取整、反射像素、共同边界与逆对齐；在相同环境对两帧 O 重新前向，与旧 FP32 原图缓存逐像素核验。只复用核验匹配的 O，把旧 O 的已对齐区域再收窄到本轮共同区。所有 2% 和 4% 视图重新评分。完整验证后报告按 G 最大、最小选出的两帧，若并列取冻结帧 ID 字典序最小者，两帧同类热图共用色标。案例只用于解释帧级差异。
