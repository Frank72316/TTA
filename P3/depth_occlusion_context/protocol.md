# 遮挡近侧与裁窗的真实周边
基线版本 aba9d08。2026-11-28 在正式推理前登记。2014 的 23 个已见场景用于复查，2005 六个、2006 二十一个公开 GT 布景用于冻结复验。每组固定 FullSize 左图和逐图标定；2005 用 Illum1/Exp1，2006 用 Illum1/Exp2。2005/06 的 D=0 缺测，其余按 0.160×3740/(D+dmin) 米；2014 复用已核验 PFM。三年跨年 RGB 做内容哈希、低频感知哈希、缩略图相关和人工全场景拼图核查；复用道具本身不足以认定同一布景。可辨认同布景只保留早年一份，2014 已见者优先排除重叠复验样本。编号系列同年同簇，2014 一图一簇。具体 ID、可用状态和内容哈希见 scenes.csv。iBims 高清仍缺配对数据。

**干预。** B 与旧 T 使用原实现。核心窗由原生宽高各 60% 半向上取整，锚定四角。大画布的两个维度取离相应核心编码器尺寸的 4/3 最近的 14 倍数，半向上。以核心的源像素/编码器像素比、角锚点和半像素中心坐标，独立确定大画布的连续源矩形。以官方相同 Pillow 重采样和 RGB 归一化取真实外圈 R；P 用核心在源栅格上做不重复端点的镜像延拓后按同一连续映射采样。二者在原核心编码器矩形内均直接写入原 T 的 RGB 栅格，避免重采样核跨过核心边缘造成微小改变。四角分别贴大张量同名角。断言整个归一化核心逐元素等于 T，直接把大张量交给模型。输出在大张量取核心、再 bicubic 对齐回原核心，align_corners=False。尺度取各自核心中央 80% B/窗 中位、截到 [0.5,2]，距离权重及与 B 各半的融合沿用 T。记录固定 T 尺度的 RP、25% 融合，以及纯校正拼图 C。整图输入和所有窗均只取原生 RGB。

**判定顺序。** 唯一主要比较为近侧 MAE(T)−MAE(R)。依次读近侧 B−R、P−R（独立真实周边贡献）、固定 T 系数的 P−R，以及 R 对 B/T 的远侧与等权 MAE。检验新数据旧 T 对 B 的远侧优势是否重现。25% 融合、R 对 25%、有符号残差、跳变误差、全图 MAE、深度推移的方向与相应误差变化均为辅助。事后角色参照只在近侧使用 B、远侧使用 T。记录近/远去重采点计数，移动分组以相同像素上的 T−B 符号判别（严格零单列），误差变化按 |T−GT|−|B−GT|。逐图边界先分侧均值再等权。逐图结果在同簇内取均值再跨簇等权；配对区间按簇抽 10,000 次、种子 2026、双侧百分位。分别报告 2014、两年合计及两年各自；使用上一轮原封不动的 GT 资格与宽度，范围 (0,20] m。零合格界面或非有限预测单列覆盖。收益正代表所列第二种方法误差较低。

**计算与案例。** 两张空闲 4090 按 UUID 绑定，每个布景全部条件同卡，R/P 运行先后按冻结序号交替。在两种典型分辨率的合成图测坐标、归一化、反射、回映及计时。2014 复用 5 个原生预测，新增 8 个；新场景新增 13 个。相同 B 在每个策略部署中计一次，实际两库新增共计划 535 个；合成单列。评价、哈希、缓存 I/O 单列于推理计时外。主表部署耗时从已解码 RGB 起，记录 B、T、R、P、25% 真实数据共享组件计时，2014 缓存的 B/T 耗时标明旧实测来源；另给合成图完整路径计时。案例在独立复验有合格界面的场景中按冻结顺序各取首个近侧收益正、非正场景；若缺，再从 2014 取。界面和角窗选择均按空间位置（距中心最近的合格界面，选择包含该界面且中心最近的窗）。公开小型结果，完整像素缓存在 Asus。
