# 反向平移让区域距离差估得更准，远近排序改善了多少？

在真值均深相差至少 0.10 m 的区域对上，同样每帧推理三次，反向搭配比同向搭配的**区域距离差 MSE 低 0.000745 m²**（场景配对 95% 区间 **0.000411 至 0.001187**）。

**严格远近正确率净增 0.0651 个百分点**（95% 区间 **+0.0199 至 +0.1122**），从 95.1925% 升到 95.2576%。

排序改善小，主要因为**很少跨过零点**：13,763 个区域对中只有 66 对至少一次换边；在两个固定小幅方向的 27,526 次比较中，87 次跨零，52 次纠正、35 次改错。

| 主分析策略 | 区域距离差 MSE（m²） | 严格远近正确率 | 预测同分 |
|---|---:|---:|---:|
| 原图 | 0.471087 | 95.1888% | 0 |
| 同向平移，原图＋左左或右右 | 0.470106 | 95.1925% | 0 |
| 反向平移，原图＋左右或右左 | 0.469362 | 95.2576% | 0 |

反向相对**只看原图**平均少 0.001725 m²（95% 区间 −0.005102 至 +0.008720），远近正确率高 0.0688 个百分点（−0.0155 至 +0.1511）。这两个区间都容许反向略差于原图。连续指标直接比较两个区域的均深差，共有的加性偏移会消去；上一轮逐像素的 0.001000 m² 没有进入本轮估计。

**从分差到判定。** 固定左移 2%，将大幅方向从左改右（LL→LR），26 次错→对、18 次对→错、13,719 次判定不变；固定右移 2%（RR→RL），分别为 26、17、13,720 次。两个方向均无预测同分。按部署时两方向等概率、帧内区域对等权、最后帧等权计算，**纠正率 0.1909% − 改错率 0.1258% = 净增 0.0651 个百分点**。两个方向的比较来自同一批区域对。[逐方向计数](transitions.csv)

近同深对也出现距离误差下降，其排序差的区间容许低 0.650 或高 0.185 个百分点。真值恰好相等的区域对、帧和场景数均为 0。[各层三策略表现及区间](summary.csv)

**两个按冻结顺序选出的案例。** nyu_1180 中 A 比 B 远 0.53437 m；LL→LR 将预测从 +0.72837 拉近到 +0.64379 m，两次都选 A。nyu_1052 中 A 比 B 远 0.13543 m；同样的换向让预测从 −0.00339 变为 +0.00248 m，刚好把远近判对。[查看 A/B 方窗、真值与全部配方预测](cases.jpg)

**范围与核验。** 本轮复用 128 个 NYU 开发帧、95 个场景，CPU 离线分析，**新增模型前向 0 次**。每帧 16 个固定窗全部合格，15,360 个无序区域对的连续与离散指标共用相同真值和掩膜。区间来自 10,000 次场景整簇配对重采样。逐区域对独立核验乘积公式，最大绝对残差 2.45×10⁻¹⁴ m²；640 个预测数组的哈希全部匹配。[逐区域对明细](region_pairs.csv) · [逐帧结果](frame_results.csv) · [复现命令](README.md)
