# 区域距离差与远近排序：冻结协议

本协议在读取像素预测前写定。上游为 Frank72316/TTA 的 `3e0ea7c340a5bf27faf784b6e16a45a27571a7f0`。复用已研究的 128 帧、95 场景。只读 NYU 归档及五个已逆对齐的 FP32 数组 O/L2/R2/L4/R4，逐帧逐视图核对身份与 SHA-256；在 CPU 上以 float64 计算。每套三视图配方的部署成本沿用上一轮，本轮新增模型前向数为零。

**抽窗与分层。** 共同视野在原图为 x∈[26,614)、y∈[0,480)，局部坐标宽 588、高 480。4×4 等分网格，每格几何中心四舍五入（半数向上）至整数像素边界，取 [cx−16,cx+16)×[cy−16,cy+16)。局部 x 起点 58、205、352、499，y 起点 44、164、284、404；编号 1–16，行优先。以真值 (0,10] m 为有效区，每窗至少 922/1024 像素有效。同一窗全部预测与真值在同一掩膜上求均值。只枚举 A<B。用源真值的整数毫米总和和有效像素数精确判断相等及阈值归属，米制运算用 float64。主层为 |d|≥0.10 m，另列 0<|d|<0.10 m 与 d=0；主层分为 [0.10,0.30)、[0.30,1.00)、[1.00,∞)。d=0 只报告数量和可计算的连续指标，排序无定义。

**连续与离散指标。** d 为真值均深 A−B，x_v 为单视图均深 A−B，正值为 A 更远。LL、RR、LR、RL 的前后字母分别指 2%、4% 平移方向，均另含 O。每配方独立取三视图的 x 均值 q，计算 (q−d)² 及严格同号指示数；同分指 q=0，纳入分母。先平均同向或反向的两种配方表现，再对一帧内合格区域对等权，最后非空帧等权。每层按该层有贡献的场景有放回抽同样数量的整簇，抽中场景的全部合格帧和条件共同进入，按副本帧数取平均；场景按名称排序、种子 20261128、10,000 个副本，取 2.5% 和 97.5% 分位。主对比为 G=MSE同向−MSE反向（m²）和 A=正确率反向−正确率同向（百分点），比较原图时同样以正值为反向较好。

**机制与演示。** 对所有合格区域对（包括近同深与真值相等）独立验算 G=(x_L2−x_R2)(x_L4−x_R4)/9。对 d≠0，固定 2% 方向比较 LL→LR 及 RR→RL；分类为错→对、对→错、涉及预测同分、其余判定不变，保留各方向完整九格。计数与帧等权率分别记录。A 的对账含同分→对和对→同分。同时统计两个方向至少一次严格跨零的区域对。案例仅取主层，优先按上游冻结帧顺序、A、B、LL→LR 优先于 RR→RL。要求该区域对的平均 G>0，且该方向配方的平方误差严格下降，分别取严格判定维持（对→对或错→错）和错→对的首例，并记录各类可用数。并列图给出全部实际配方值。冒烟用冻结前两帧，核验通过再分析其余样本。
