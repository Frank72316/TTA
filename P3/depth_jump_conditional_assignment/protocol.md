# 条件重配的分析规则

使用提交 78a419dad2f272da083a0693611d57ef81c614a7 的全部 50 个 Middlebury 布景、原边界索引、三点中位数及缓存融合实现。2014、2005/06 分开，主方法 R，对照 T。先复现全部场景的 A全乱、A真实和上一轮两批总位置收益，再计算条件指标。CPU 计算，无模型推理。两批都是回顾性分析。

- 在每场的横向扫描和纵向扫描内分别取全图 B 两侧三点中位深度之差的绝对值。该量交换两侧也相同。单位 mm，排序、作差和重配用 float64；原生预测保留已有精度。只用布局中的扫描轴和这一 B 预测量建档。分位点用 NumPy 线性 20%、40%、60%、80% 分位数，相等切点先合并，等于切点归入较低档。空方向及空档不产生 MAE 权重。记录按方向和按档的实际边数、边界、单元素档及覆盖率。
- 全乱、方向、方向加落差五档均在场内均匀重配，允许留在原位。在任一非空组中对所有接收边和所有供给修正计算精确绝对误差期望，以实际边数加权。唯一主指标为 A条件−A真实，正值表示组内仍有对应原位置的额外精度；三项差与总收益逐场核验，所有负值保留。
- 大小对照在不改变轴及该轴各档人数的条件下打乱档标签，场内分别 100 次；B、T、R 的边顺序相同，R/T 使用同一次置换。随机流以种子 2026、冻结场景序号及轴号初始化，跨次连续取样。每次均重新算组内互换的精确期望。对照差定义为 A人数对照−A条件，正值表示以真实 B 落差分档较同尺寸随机档误差低。100 次先在同场平均，不作为独立样本。另用可留原位的理论自配概率，校核该对照的长期期望。
- 先逐场、再在旧编号系列内取平均、最后各簇等权。配对 10,000 次双侧 95% 百分位 bootstrap，种子 2026，按旧程序的批次和簇名顺序共用抽样索引。报告 2014 的 23 场／23 簇和 2005/06 的 27 场／17 簇。区间反映簇间抽样差异。只对预设的 R 主指标作首要判断；其余项解释误差来自哪一步。
