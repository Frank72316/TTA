# 平移方向搭配能否在独立 NYU 场景复现？

**同预算下的连续误差优势得到独立复现。** 在 84 个从未用于仓库旧实验的拍摄场景中，每帧同样推理三次，反向平移比同向平移的区域距离差 MSE 低 **0.001088 m²**。远近正确率高 **0.0193 个百分点**，方向与开发集一致，复验仍不确定。

**场景怎样隔离。** NYU 官方测试划分共有 215 个具体拍摄场景、654 帧。早期 64 帧和后续 128 帧分属 131 个场景，排除这些场景的全部 436 帧，包含 244 个虽未直接用过、但来自旧场景的帧。其余 84 个场景的 218 帧全部纳入，场景 ID 交集为零。场景来自官方 MAT 的 scenes 字段，归档编号加一后与官方测试索引逐一相符。主指标与次指标共用真实均深差至少 0.10 m 的区域对，先帧内平均再帧等权，区间按具体场景整簇配对重采样 10,000 次。[冻结记录](freeze.json) · [场景排除清单](excluded_scenes.csv)

**何时改变了远近判断。** 固定先左移 2%，将第二个平移从左 4% 换为右 4%（LL→LR），27 次纠正、41 次改错、23,300 次判定保持；固定先右移 2%（RR→RL），48 次纠正、25 次改错、23,295 次保持。两条路径都没有预测同分。23,368 个区域对中仅 118 对至少一次改判。按方向等概率、帧等权，纠正率 0.1629% 减去改错率 0.1435%，得到净增 0.0193 个百分点。三个预设距离层的连续误差差值均为正，各层结果仅作解释。全体 26,160 个区域对的乘积公式最大残差为 1.01×10⁻¹⁴ m²。[转移计数](transitions.csv) · [含分层区间的汇总](summary.csv)

**预算怎样用。** 固定三次时，以区域距离差误差为目标，应选反向搭配；远近排序收益尚未在独立场景得到确认，区间允许低 0.0202 或高 0.0626 个百分点。与只看原图相比，反向的 MSE 实际**高 0.000560 m²**（以“省下误差”为正，95% 区间 −0.005502 至 +0.003810），正确率**高 0.0220 个百分点**（−0.0392 至 +0.0826）。两项区间均跨零，目前没有证据表明为此每帧多做两次前向能稳定获益。
