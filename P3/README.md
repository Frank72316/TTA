# P3 · 推理次数的边际收益受共同偏差限制

**状态：待验证。** 飞书《TTA idea》第 2–3 页定义假设，第 4 页“实验三”给出验证方案。

固定增强类型和幅度，比较每图 **1、2、4、8 次推理**的任务表现和耗时，再固定次数改变幅度。核心问题是多算一次还能消除多少误差，以及何时值得换一种增强。

方案提出估计共同偏差、单视角误差方差和视角间误差相关性，将预测的预算曲线与实测曲线对照，估计有效视角数及边际收益拐点，并在留出集比较不同采样策略。

已完成的 [P2 平移复验](../P2/translation/report.md) 在固定三次预算下改变增强组合。该实验提供了参数方向与改判的证据；P3 所需的完整预算曲线、共同偏差估计和策略对照仍待测量。
