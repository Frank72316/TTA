# 模型输入分块相位能否预言平移配方的胜负

## 数据与先验预测

使用既往 NYU 开发清单中的 95 个场景、128 帧。只读 frame_id、图片路径及场景名，按名称排序后用 Python Random(20261128) 抽 32 个场景，每个场景在按 frame_id 排序的原有帧中均匀抽一帧，固定清单及 SHA-256。冒烟用清单前两帧。全部保留。此处为机制开发实验。模型固定为项目的 Depth Anything V2 Metric Indoor Small，FP32，TF32 关闭。

正方向定义为内容向右移。下表用两个位移都向右时的余数命名组别，单位均为模型输入像素。G 定义为同向平均区域距离差 MSE 减反向平均区域距离差 MSE。G 正表示反向好。

## 干预与评价

1. 每帧只做一次官方 resize/normalize。完整 480×640 RGB 得到 518×686 张量；从左右各留出 42 像素（3 个整块），中央 518×602 作为两种填边都使用的 O。模型网格原点与完整张量的网格对齐，模型所见尺寸固定。主实验在中央张量上右/左移 11、17、25、31，按 reflect（不重复端点）补边。主实验 32×9=288 次唯一预测。边缘对照从已预处理的较大张量直接截取相同位置的移动窗口，真实边条取自预留上下文，共享同一 O，另需 32×8=256 次。完整设计 544 次，两阶段先冒烟后续跑。控制列只改变新露出的边条；逐像素验证重叠区、逆对齐、公共视野。部署每套三视图用 3 次前向。
2. 在模型分辨率先以整数逆对齐，再用 bicubic、align_corners=False 映回原始 RGB-D 坐标。全部视图/填边/配方用相同的中央共同视野。源图左右各剔除 ceil((42+31+2)×640/686)=70 列，额外 2 个模型像素保护 bicubic 插值支撑，保留原图 x∈[70,570)、全高。共同视野内取 4×4 网格，每格中央取 32×32 原图像素窗，中心按半数向上，窗内至少 90% 真值有效（0<深度≤10 m）。用相同有效像素取各预测和真值均深。每两个窗作无序对，主分析固定真值均深差绝对值≥0.10 m，以整数毫米和及像素数判门槛。区域清单与模型输出无关。
3. 对每组 a,b 分别计算 O+La+Lb、O+Ra+Rb、O+La+Rb、O+Ra+Lb。每个配方先等权平均米制预测，再评价区域深度差平方误差，然后同向、反向各自等概率平均。先区域对后场景等权。原图 O 及固定反向另报；预言规则在同余数组取反向、异余数组取同向，四组等概率。全体三视图的期望均深相同，差别来自左右镜像配方误差。以单视图区域差 x 核验逐项 G=(x_La−x_Ra)(x_Lb−x_Rb)/9，阈值 1e−12 m²。边缘两臂单列。

## 判据

主实验有两个共同必要条件。按场景先等权平均同组两个幅度搭配，分别对 G同余 和 G异余 计算完整场景配对 bootstrap 双侧 95% 百分位区间（10,000 次，NumPy 种子 20261128，共用重采样索引）。两项区间分别全部在正侧和负侧才称预言的翻转得到支持；均值方向满足但有区间跨零则写方向一致、证据未定。若只见同余减异余的区间为正而未满足翻转，称相位类别调节了增益。另列每组单独 G、配对场景数和场景散布。所有组严格共用 32 帧。若有帧无合格区域对则明列，按同一非空场景交集估计；禁止换帧。

边缘对照用相同判据和同一批场景。若只有反射臂满足，不能把选择规律推广到真实边条；另报两臂各主指标及相位对比的配对差区间。即使两臂均满足，本试验也只能区分预先指定的两种符号模式，不能分离分块、位置编码和解码器重采样各自的因果贡献。四组的平均位移幅度匹配，但仍只覆盖所选四个幅度。

仅在两臂均支持预言的严格翻转后进入未用 RGB-D 数据的独立验证，另冻结场景、指标和同预算均匀覆盖 14 相位的对照。固定反向与一次原图分别回答同预算选配和追加推理是否值得。主结果不按预期符号筛选像素、场景或例子。
