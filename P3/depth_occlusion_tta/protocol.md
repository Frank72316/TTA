# 局部放大 TTA 的遮挡边界精度 · 正式冻结

冻结于 2026-11-28 21:32（UTC+8），在加载任何正式预测前。完整实验定义见 [设计原文](design_spec.md)。按用户最新指示使用可用多卡，无截止时间。主库 iBims-1 的官方 100 个核心 ID 全部进入预期清单，仅接受同坐标 1500×1000 RGB 和米制激光深度；外部库为 Middlebury 2014 的 23 个公开 perfect 场景。未就绪行留在分母盘点，两个库独立解释。样本领取、配准图排序按 SHA-256(dataset/id)，每图所有条件在同一 UUID 上运行。正式样本不做效果预试验。

- 主检验为 N 下跳变两侧等权 MAE 的 B−T，核心机制检验为同图 (B−T)N−(B−T)L，两者均以毫米计。两项双侧 95% 区间下界都大于零才能作联合声明。以真实房间为簇、房间等权；无可核实的房间元数据时按图，Middlebury 按场景。NumPy 种子 2026，整簇配对重采样 10,000 次。无有效边界时记录原因，全部策略共用边界。次比较为窄减宽收益、H−T MAE、原始融合减校正融合、共同原生 B 与尺度下 L 窗减 N 窗。原生 G 的最大、最接近中位、最小各取一例，若相等按冻结顺序。
- 冻结项目模型和官方 DPT 全视场预处理、FP32 关闭 TF32。依模型配置统一取轴深 (0,20] m。PFM 用带符号 scale 识别端序、翻转行、按其绝对倍率读取。L 在 sRGB 编码 RGB 的 0–255 数值空间中，PyTorch CPU area 浮点降采样、bilinear 半像素中心放回，最后裁至 [0,255]、半数向上转 uint8。输入大小取 B 的真实张量。N 与 L 均重新走官方 B 路径。四窗宽高独立按 0.60 四舍五入，按左上、右上、左下、右下顺序，四窗固定 batch 4。米制输出以 bicubic、align_corners=False 恢复。中央 80% 以像素中心判断，尺度为有限正比值的通常中位数（偶数取中间均值），没有有效比值回退 1。融合距离用像素中心距窗边除以对应窗边长度。预测缓存保留 float32。
- H 用两个库各自代表性原始尺寸，无标签固定随机 RGB；iBims 1500×1000，Middlebury 在 23 个实际比例中取中位那张的尺寸。目标边 518×倍率四舍五入，再经官方预处理到 patch 倍数；逐图限制网络宽高均不超过原片，高档若受限只允许退至下一个预设档。记录所有候选、重复、超限和 OOM。单独预热 2 次、同步测 7 次，取未超过 T 中位时间的最大档。同图正式 B/T 共享原图前向，从解码后的 RGB 到 CPU 上原坐标深度，T 实测包括 B 和尺度融合，不含缓存写盘、GT 与离线诊断。原生中的 B、T、H 均单列。
- GT 规则及容差完整遵循 design_spec 第 4 节。两侧 1/2/3 B 像素映回原图，以界面中点为原点，floor(x+0.5) 最近采样，两端之间整段均须有效。取近端向内连续原生像素数除以该轴缩放比作跨度；第二个反向合格界面须返回更远深度，超过 24 B 像素记右删失。按图对各侧像素分别去重，两侧各占一半；跳变幅度每条合格界面计一次。官方边对齐时取 1 个 B 像素内的自动界面，平面腐蚀 5 个 B 像素按实际轴比例计算，以 N 亮度梯度选点固定两条件；不存在同坐标辅助标注时留空。
- 另存全部合格界面、两条件亮度对比、窗尺度、前后景有符号米制误差、全图 MAE/AbsRel。共同锚点用 N 的 B、N 的四个裁窗尺度及固定权重，仅将窗预测换成 L。配准审计图每库先取哈希最小 6 个，不用结果选位置；结果案例优先取距图心最近的窄边，缺失则取距中心最近的主边。高分辨率比较在正式延迟比不在 [0.8,1.2] 时据实限定预算解释。
