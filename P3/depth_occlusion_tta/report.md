# 局部放大能把遮挡边界的深度估得更准吗？

**iBims-1 的正式主检验未能估计。** 100 个预期 ID 均找到，但 TUM 公开发布的两个 core 包中，100 对 RGB 与激光深度均为 640×480。官网列有 1500×1000 规格；辅助包中的高清手持照片没有对应高清激光真值，另一公开镜像也只有 VGA。高清主样本为 **0/100**。[逐图盘点](inventory.csv) · [TUM 数据说明](https://www.asg.ed.tum.de/en/lmf/ibims1/)

**Middlebury 的 23/23 个外部场景没有显示稳定的边界净改善。** 原生高清的默认全图 B 与尺度校正裁窗融合 T 的边界 MAE 分别为 **1,144.2 和 1,147.9 mm**。T 在 13 场改善、10 场恶化，平均收益 **−3.6 mm**，相对降幅 −0.32%。削弱原片细节后，裁窗方案的相对表现进一步下降；这条降采样链影响了收益，但原生方案本身尚未稳定胜过全图。

| 预设比较，正值表示改善 | iBims-1 高清 | Middlebury 平均差［场景配对 95% 区间］ |
|---|---:|---:|
| 原生条件的边界收益 G_N | 缺高清 GT | **−3.6 mm**［−20.8, +12.7］ |
| 去细节条件的边界收益 G_L | 同上 | −12.2 mm［−27.5, +1.4］ |
| 机制检验 G_N − G_L | 同上 | **+8.5 mm**［+1.7, +15.9］ |
| 窄组收益减宽组收益 | 同上 | −14.7 mm［−58.3, +18.3］，19 场 |
| 单次高清全图 H 的 MAE 减 T 的 MAE | 同上 | +369.2 mm［+220.2, +535.6］ |

**前后景受影响的方向相反。** 原生条件下，T 让近侧 MAE 增加 **61.4 mm**，让远侧 MAE 减少 **54.2 mm**。真实跳变幅度的绝对误差从 344.2 降至 340.0 mm，收益区间［−45.0, +44.1］mm。全图 MAE 改善 3.2 mm［−10.7, +16.4］。窄、宽比较的同图集里，两组分别为 −23.0、−8.4 mm；当前数据不足以判断窄结构更受益。

**原片信息与尺度校正都有可量化的作用。** 固定原生全图、四个原生尺度及窗权重，只把降质窗换回原生窗，边界 MAE 减少 **34.2 mm**［18.4, 51.4］。原生的未校正融合 MAE 为 1,309.3 mm，尺度校正直接改善 **161.4 mm**［91.1, 225.4］。即使如此，校正后的 T 仍未稳定胜过 B。原生和降质的全图预测本身平均相差 49.6 mm，两项机制比较回答不同的问题。[尺度与覆盖明细](diagnostics.md)

H 的正式中位延迟为 T 的 **0.60 倍**，超出预设的同耗时范围；H 更快，但误差更大。对这 23 场，默认全图成本最低，追加四窗的主要可见收益在远侧。共评价 **188,235** 条界面，每图近、远侧各占一半，按场景等权，无新增人工标注。7 张 RTX 4090 共完成 253 次正式前向，另有 198 次合成校准及预热。PFM 单位勘误在比较模型误差前完成；独立 CPU 复算了两项核心指标、区间和案例顺序。[单位核验](pfm_correction.md) · [复现命令](README.md)
