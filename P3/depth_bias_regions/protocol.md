# 冻结方案

从既有 128 帧对齐预测构造 p₂、p₄ 及 p₂ 加帧内平均预测位移。主比较为 p_shift 到 p₄ 的帧均 MSE 降幅，另报均值项及总收益。以四邻域任一有效差的跳变标记种子；四邻全有效方可判定，无法判定的有效像素单列。膨胀用欧氏半径 3 的圆盘。分区共享同一帧级平移量。对同帧区域均值乘面积比后跨帧平均。沿用旧误差口径，并做直接预测精度审计。

95 个场景等概率整簇有放回重采样 10,000 次，种子 42，使用百分位 95% 区间。同分单列。前两个冻结 ID 做冒烟检查。按冻结 ID（再按预设参数顺序）取首个有益和首个有害的实际案例；深度以空间收益的正负选例。结果限于当前样本。
