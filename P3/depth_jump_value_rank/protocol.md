# 冻结方案｜低通修正的数值与排序

起点为 `79680d9963fb2957367ba82042fbd7dabe444bb7`。在查看交叉格前固定以下规则。使用 Asus 原有 B/H/L 缓存和每侧三点中位数，在同一布景、原扫描方向、B 预测落差绝对值原档内比较。2014 的 23 场／23 簇和 2005/06 的 27 场／17 簇分别分析。主要解读 2005/06。一次性纳入 243,818 条界面和 495 个既有非空档，沿用两套共用尺度。仅在 CPU 运行。

- 先对两个批次和两种尺度从真实深度图复现 H、L 逐场 MAE 和总优势 D，核对上轮直接对比及区间的符号反转，然后计算交叉格。
- 第一字母为有符号修正值来源，第二字母为接收边的有符号排序。每档内把有序供给数值按顺序放到接收边。接收排序相等时，一条边对该段全部可接收值的绝对误差取算术均值；GT 仅用于评价。HH、LL 等于实测误差。单位 mm，正收益表示前一格比后一格多错的毫米数。
- 路径一先换数值 HH→LH，再换排序 LH→LL；路径二先换排序 HH→HL，再换数值 HL→LL。D＝HH−LL。V、S 分别为两个背景下换值、换序的平均收益。交互定义为低通排序下的换值收益减原生排序下的换值收益，亦等于低通值下的换序收益减原生值下的换序收益。逐档及逐场核验 D＝V＋S。
- 只换均值时按档将 u_H 平移 mean(u_L)−mean(u_H)，保留原排序及距均值的偏差。报告该格 MAE、相对 HH 的收益、同一 H 排序下再换到完整 L 数值所改变的误差，以及相对实测 LL 的差。均值和排序都只读取预测。
- 先按实际边数求场均 MAE，再簇内场景等权、簇间等权。所有差值在同场内配对。沿用上轮生成器次序、种子 2026、10,000 次场景簇配对 bootstrap、双侧 95% 百分位区间。主口径 H/L 共同用原生尺度，敏感性共同用低通尺度。保留两条路径、交互及负结果。用另一种算法独立核验并列处理。本轮为回顾性输出归因，完成后收束既有样本的分档分析。
