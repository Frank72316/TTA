# 平移复验协议

本协议在独立样本抽取、推理和策略分析前写入。抽样清单与本协议的 SHA-256 一同冻结。旧 64 对只用于诊断，独立样本用于以下主比较。

1. **样本**　使用上一轮固定 revision 的 ImageRewardDB validation metadata 与原图 ZIP。以 NFKC、casefold 和空白合并后的文本去重，并排除旧 64 个 prompt_id、旧规范化原文和旧图像文件 ID。仅在同一 prompt_id 和同一原文的记录内取名次为正且不同的两图，rank 数值小者为人工赢家。用 Python random.Random(2026) 从按规范化原文排序的合格池均匀无放回抽 256 条；不足时使用实际合格数。同一规范化原文有多个组时先等概率选组，再均匀抽无序图对，独立随机交换 A/B。保留送入模型的原始文本。人工标签、分差、任何先前模型输出都不参与内容筛选；标签仅用于确认存在严格名次。
2. **输入与预算**　同一 RGB 原图独立生成 O、B/C 0.90、0.95、1.05、1.10 和 T 左右上下各边长 3%（取整半数向上、reflect 填充），直接复用 P2 的图像变换与官方 HPS v2.1 验证预处理。每张图 13 个模型输出，原生 fp16 完整保存。每种三次策略只看 O 和两个视图，对 A/B 用相同参数，等权均值。BB、CC、TT 各枚举 6 个不同版本对，BC、BT 各 16 个组合。严格异号为翻转，恰好等分单列；“改判”包含选择与同分之间的变化。每个组合先决策，再取正确/错误/同分比例。原图本已同分时不称为纠正或改错。
3. **主终点**　每对的贡献为 BT 的严格正确比例减 BC 的严格正确比例，对全部独立图对求均值。共同亮度档赋予相同权重。95% 区间用 numpy default_rng(2026) 对完整图对有放回重采样 10,000 次，以线性插值的百分位数计算。报告 BT/BC 的正确原始组合数、期望选对数、百分点差及区间。三类原始状态分别对账，比较各策略错→对与对→错的期望数，同分转移保留。区间跨零时不宣称总体准确率方向确定。
4. **新增纠正和损失**　原图选错、BT 至少一个组合纠正且 BC 全部未纠正为 BT 新增纠正支持集；另查 BB、CC 和 TT，以区分单用平移可达到的结果。损失以原图选对、BC 至少一组保持正确、BT 至少一组严格选错为宽口径，另标 BC 全部正确的严格子集，BT 部分/全部 16 组改错分列。逐对列 BT−BC 的原始贡献、最大正负及所有并列，期望对数允许小数。样本级集合与组合平均的净数分开解释。
5. **原始分差分组**　先抽出 d₀=0；其余按 (abs(d₀), 冻结 ID) 排序，用 numpy.array_split 等量四分。边界同值按 ID，不按结果分组。典型位移为同组各图对、各族四版本的 abs(Δ) 中位数，每对权重相同。另给每对 T 与 C 四版本绝对位移中位数的配对比较。各组按独立图对计 BT/BC 至少一次改判的并集及各自数量，同时给严格翻转和主终点。组内描述不作显著性筛选。
6. **方向检查**　对每个 BT 改判图对列四个方向各自在四档亮度中的改判、严格翻转、最终选对/错/同分计数。另报触发方向数、亮度档数、只在一格出现及多方向复现数。将“多个方向”定义为至少两个方向各有一次，“一个方向跨多档复现”定义为该方向至少两档。方向复现描述同一图对的参数稳健性；同时观察 O+单方向 T 及同向四亮度是否均触发，以辅助判断。没有区域注意力、构图类别或普遍成因的推断。
7. **恒等式与发现样本**　每个三次组合验证 3d_agg = 3d₀ + Δ₁ + Δ₂，比较同分母的分子以避免除三引入舍入。旧 64 对从原始缓存重算 P2 的全部十策略、所有 120 种组合，以任何判定变化找旧案例。案例页只描述输入与输出。无论主终点正负，按同一规则交付两张统计图、案例页、逐对数据与中文报告。
