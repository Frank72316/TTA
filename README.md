# 测试时增强如何改变图像偏好排序

这个项目用 HPS v2.1 给同一提示词下的两张候选图评分，考察亮度、对比度、JPEG 压缩和平移如何改变两图分差，以及这些改判是否与 ImageRewardDB 对原图的人工排名一致。

新加入的队友可以先读 [P1/P2 阶段交接报告](tta_project_handoff/TTA阶段交接报告.pdf)，再接续 [P3 实验交接报告](tta_project_handoff/P3交接报告.md)。阶段报告第 5–7 页并排展示了真实候选的原图、扰动图和分数。另附[可编辑源稿和重建说明](tta_project_handoff/README.md)。

| 实验 | 样本与问题 | 入口 |
|---|---|---|
| [P1 · 亮度与提示词](P1/README.md) | 在 64 对图上比较夜景提示词对调亮响应的影响，分解两张图共有和不同的变化，再用跨提示词重配检验同步性 | [单图分解](P1/decomposition/report.md) · [重配对照](P1/pairing/report.md) |
| [P2 · 增强互补性](P2/README.md) | 每图固定三次评分。先用 64 对比较增强组合，再用 256 个新提示词复验用平移替换对比度带来的纠正与改错 | [64 对发现](P2/report.md) · [256 对独立复验](P2/translation/report.md) |
| [P3 · 推理次数的边际收益](P3/README.md) | 在单张 L4 上比较每图 1、2、4、8 次推理的准确率和耗时，再做幅度、留出策略和米制深度对照 | [P3 实验报告](P3/report.md) · [预算曲线](P3/results/budget_curves.png) |

编号沿用飞书《TTA idea》的研究假设。P1 与 P2 的发现样本共用 64 对图，P2 的平移复验使用独立的 256 对。P3 用这 256 对开发协议，在另外 88 对提示词及 NYU Depth V2 抽样帧上复验。人工排名适用于原提示词 P0 和原图，Q0、Q1 用于分析模型自身的响应。P4 关于聚合空间与任务变换律的对照仍待验证。

各实验目录保留冻结清单、原始评分、逐对结果、分析代码和图表。从缓存复算请使用相应 README 中的分析命令。从原图重新推理还需要按先导实验的说明准备公开数据、模型权重和 GPU 环境。

实验报告统一使用 Markdown，需要打印或交接时另附 PDF。后续实验沿用这两种报告格式。
